# 🔤 Word Search — LeetCode #79

## 📌 Problem

Given an `m x n` board of characters and a string `word`, return `true` if the word exists in the board.

The word can be constructed from letters of **sequentially adjacent cells**, where adjacent cells are:

- Up
- Down
- Left
- Right

The same cell **cannot be used more than once** in the same word path.

### Example

```text
Input:

board =
[
  ['A','B','C','E'],
  ['S','F','C','S'],
  ['A','D','E','E']
]

word = "ABCCED"

Output:
true
```

One possible path is:

```text
A → B → C
        ↓
        C
        ↓
        E → D
```

---

# 🧠 Brute Force Thought Process

We don't know where the word starts.

So the first step is:

```text
Try every cell as a possible starting point.
```

If the current cell matches the first character of the word, we try to build the remaining word from that cell.

For every matching cell, we have up to **4 choices**:

```text
        Current Cell
       /     |     \
     Up    Down   Left   Right
```

We continue exploring until:

1. We find the complete word → `true`
2. The path becomes invalid → backtrack

This naturally leads to:

```text
DFS + Backtracking
```

---

# 🚀 Approach — DFS + Backtracking

### Step 1 — Try Every Starting Cell

We iterate through the entire board:

```java
for(int i = 0; i < row; i++){
    for(int j = 0; j < col; j++){
```

If:

```java
word.charAt(0) == board[i][j]
```

then this cell can be the starting point.

We start DFS from there.

---

### Step 2 — Check Whether Current Cell Is Valid

Inside DFS, we check:

```text
Out of bounds?
Already visited?
Current character doesn't match?
```

If any of these conditions are true:

```text
return false
```

---

### Step 3 — Mark Current Cell as Visited

Once the current cell is valid:

```java
visited[i][j] = true;
```

This prevents us from using the same cell again in the current path.

---

### Step 4 — Explore 4 Directions

From the current cell, we recursively explore:

```text
Down
Up
Right
Left
```

Your code:

```java
if( BFS(board,i+1,j,index+1,word,visited) ||
    BFS(board,i-1,j,index+1,word,visited) ||
    BFS(board,i,j+1,index+1,word,visited) ||
    BFS(board,i,j-1,index+1,word,visited))
```

Each recursive call searches for the **next character**.

Therefore:

```java
index + 1
```

---

### Step 5 — Backtrack

If none of the four directions works:

```java
visited[i][j] = false;
```

This is the most important backtracking step.

It means:

> "This path didn't work, so undo my choice and allow this cell to be used in another path."

# 💡 Important Observation

The problem is not simply:

```text
Find the next matching character anywhere.
```

The next character must be:

```text
Adjacent
```

and the same cell cannot be reused.

Therefore, we need to keep track of the current path.

That's why we use:

```java
boolean[][] visited
```

# 🔄 Why Do We Backtrack `visited`?

Suppose we have:

```text
A B
C D
```

and we're currently exploring:

```text
A → B
```

We mark:

```text
A = visited
B = visited
```

If the path from `B` fails, we need to allow `B` to be used in another possible path.

Therefore:

```java
visited[i][j] = false;
```

This is:

```text
Choose
   ↓
Explore
   ↓
Undo
```

or:

```text
Backtracking = Choose → Explore → Undo
```

# 🧠 The Most Important Backtracking Pattern

Your solution follows this pattern:

```java
visited[i][j] = true;

if(explore next possibilities)
    return true;

visited[i][j] = false;
```

Think of it as:

```text
"I am choosing this cell."

        ↓

"Let me explore whether this choice leads to a solution."

        ↓

"If it doesn't work, undo my choice."
```

This is the exact backtracking concept you should remember.

# 🔧 Your Code

```java
class Solution {

    public boolean exist(char[][] board, String word) {

        boolean[][] visited =
            new boolean[board.length][board[0].length];

        int row = board.length;
        int col = board[0].length;

        for(int i = 0; i < row; i++){
            for(int j = 0; j < col; j++){

                if(word.charAt(0) == board[i][j]){
                    if(BFS(board, i, j, 0, word, visited)){
                        return true;
                    }
                }
            }
        }

        return false;
    }

    public boolean BFS(
        char[][] board,
        int i,
        int j,
        int index,
        String word,
        boolean[][] visited
    ){

        if(index == word.length())
            return true;

        if(i < 0 ||
           j < 0 ||
           i >= board.length ||
           j >= board[0].length ||
           visited[i][j] == true ||
           word.charAt(index) != board[i][j])
            return false;

        visited[i][j] = true;

        if(BFS(board, i+1, j, index+1, word, visited) ||
           BFS(board, i-1, j, index+1, word, visited) ||
           BFS(board, i, j+1, index+1, word, visited) ||
           BFS(board, i, j-1, index+1, word, visited))

            return true;

        visited[i][j] = false;

        return false;
    }
}
```

# 🔧 Cleaner Version

The main improvement I would make is only the **method name**.

Your method is called:

```java
BFS()
```

But because you're using recursion to go deep into one path before trying another path, this is **DFS**, not BFS.

So:

```java
dfs()
```

would be a better name.

```java
class Solution {

    public boolean exist(char[][] board, String word) {

        boolean[][] visited =
            new boolean[board.length][board[0].length];

        for(int i = 0; i < board.length; i++){
            for(int j = 0; j < board[0].length; j++){

                if(board[i][j] == word.charAt(0)){

                    if(dfs(board, i, j, 0, word, visited))
                        return true;
                }
            }
        }

        return false;
    }

    private boolean dfs(
        char[][] board,
        int row,
        int col,
        int index,
        String word,
        boolean[][] visited
    ){

        if(index == word.length())
            return true;

        if(row < 0 ||
           col < 0 ||
           row >= board.length ||
           col >= board[0].length ||
           visited[row][col] ||
           board[row][col] != word.charAt(index)){

            return false;
        }

        visited[row][col] = true;

        boolean found =
            dfs(board, row + 1, col, index + 1, word, visited) ||
            dfs(board, row - 1, col, index + 1, word, visited) ||
            dfs(board, row, col + 1, index + 1, word, visited) ||
            dfs(board, row, col - 1, index + 1, word, visited);

        visited[row][col] = false;

        return found;
    }
}
```

### Why is this cleaner?

Instead of:

```java
if(dfs(...) || dfs(...) || dfs(...) || dfs(...))
    return true;

visited[i][j] = false;

return false;
```

we can store the result:

```java
boolean found = dfs(...) || dfs(...) || dfs(...) || dfs(...);

visited[row][col] = false;

return found;
```

This makes the **backtracking step happen regardless of whether the search succeeds or fails**.

Your original code is still correct because when a recursive call returns `true`, the whole search is already finished and there is no need to reuse the visited state.

# 🔍 DFS vs BFS

Your method is named:

```java
BFS()
```

but the actual algorithm is:

```text
DFS + Backtracking
```

### Why?

DFS goes:

```text
Go deep into one path
        ↓
Reach dead end
        ↓
Backtrack
        ↓
Try another path
```

Your recursion does exactly that.

BFS would normally use a:

```java
Queue
```

and explore cells level by level.

For Word Search, DFS + Backtracking is the natural pattern.

# 🧩 Direction Movement

You explore exactly four directions:

```text
        Up
        ↑
Left ← Cell → Right
        ↓
       Down
```

In your code:

```java
i + 1, j     → Down
i - 1, j     → Up
i, j + 1     → Right
i, j - 1     → Left
```

Diagonal movement is **not allowed**.

# ⚠️ Common Mistakes

## 1. Forgetting `visited`

Without `visited`, you could reuse the same cell.

For example:

```text
A B
```

You might incorrectly move:

```text
A → B → A → B
```

when the same cell cannot be reused in the same path.

---

## 2. Forgetting to Unmark

Wrong:

```java
visited[row][col] = true;

dfs(...);

// No undo
```

This can incorrectly prevent another valid path from using that cell.

Correct:

```java
visited[row][col] = true;

boolean found = dfs(...);

visited[row][col] = false;
```

---

## 3. Checking Only One Direction

You must explore all four valid directions:

```text
Up
Down
Left
Right
```

---

## 4. Moving Diagonally

These are not allowed:

```text
↖  ↗
↙  ↘
```

Only:

```text
↑
← → 
↓
```

---

## 5. Forgetting `index + 1`

After matching:

```text
word[index]
```

we need to search for:

```text
word[index + 1]
```

Therefore:

```java
dfs(..., index + 1, ...);
```

---

## 6. Forgetting to Copy the State in Backtracking Problems

This problem doesn't store the path in the answer, but in problems where you do store a list, remember:

```java
new ArrayList<>(list)
```

rather than:

```java
ans.add(list);
```

# 🎯 Interview Explanation

> "I first iterate through every cell because any cell can be the starting point of the word. Whenever a cell matches the first character, I perform DFS. In DFS, I check boundaries, whether the cell has already been visited, and whether the character matches the current character of the word. If valid, I mark the cell as visited and explore its four adjacent cells. If none of those paths works, I unmark the current cell and backtrack so it can be used in another path. When the index reaches the length of the word, I return true."

# ⏱️ Complexity

Let:

```text
m = number of rows
n = number of columns
L = length of the word
```

We can start DFS from up to:

```text
m × n
```

cells.

From each cell, we can explore up to 4 directions.

Therefore the worst-case time complexity is commonly expressed as:

```text
O(m × n × 4^L)
```

More precisely, after the first cell, one direction is the cell we came from, so the branching factor is at most 3:

```text
O(m × n × 3^(L-1))
```

Both expressions communicate the exponential nature of the search; `O(m × n × 3^L)` is a tighter bound.

### Space Complexity

Visited matrix:

```text
O(m × n)
```

Recursion stack:

```text
O(L)
```

Therefore auxiliary space is:

```text
O(m × n + L)
```
