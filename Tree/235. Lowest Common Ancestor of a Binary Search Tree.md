# LeetCode 235 - Lowest Common Ancestor of a Binary Search Tree

## Pattern

BST + Tree Traversal

---

## Key Observation

For a BST:

```text
Left < Root < Right
```

This property allows us to determine the direction in which both nodes lie.

Example:

```text
        6
       / \
      2   8
     / \ / \
    0  4 7  9
      / \
     3   5
```

Suppose:

```text
p = 2
q = 8
```

Then:

```text
2 < 6 < 8
```

Current root lies between p and q.

Therefore:

```text
LCA = 6
```

---

# Solution 1: Brute Force (Ignore BST Property)

## Idea

Ignore BST property completely.

Use the same solution as LeetCode 236 (LCA of Binary Tree).

1. Search both left and right subtrees.
2. If both sides return non-null, current node is LCA.
3. If one side returns non-null, propagate it upward.

---

## Code

```java
class Solution {

    public TreeNode lowestCommonAncestor(TreeNode root,
                                         TreeNode p,
                                         TreeNode q) {

        if(root == null)
            return null;

        if(root == p || root == q)
            return root;

        TreeNode left =
                lowestCommonAncestor(root.left, p, q);

        TreeNode right =
                lowestCommonAncestor(root.right, p, q);

        if(left != null && right != null)
            return root;

        if(left != null)
            return left;

        return right;
    }
}
```

---

## Why It Works

The algorithm searches the entire tree.

If:

```text
p found in left subtree
q found in right subtree
```

then current node becomes the first common meeting point.

That node is the LCA.

---

## Time Complexity

Every node can be visited once.

```text
Time = O(N)
```

where:

```text
N = Number of Nodes
```

---

## Space Complexity

Recursion stack:

```text
Space = O(H)
```

where:

```text
H = Height of Tree
```

---

## Interview Flag 🚩

### Why Is This Not Optimal?

This solution completely ignores the BST property.

Even if the input was a normal Binary Tree, this solution would still work.

Therefore we are not taking advantage of:

```text
Left < Root < Right
```

# Solution 2: Recursive BST Solution (Expected)

## Idea

There are only 3 possibilities.

### Case 1

```text
p < root
q < root
```

Both nodes lie in left subtree.

Move left.

---

### Case 2

```text
p > root
q > root
```

Both nodes lie in right subtree.

Move right.

---

### Case 3

```text
p < root < q
```

or

```text
q < root < p
```

Current node lies between p and q.

Current node is the LCA.

---

## Code

```java
class Solution {

    public TreeNode lowestCommonAncestor(TreeNode root,
                                         TreeNode p,
                                         TreeNode q) {

        if(root == null)
            return null;

        if(p.val < root.val &&
           q.val < root.val)

            return lowestCommonAncestor(
                    root.left, p, q);

        if(p.val > root.val &&
           q.val > root.val)

            return lowestCommonAncestor(
                    root.right, p, q);

        return root;
    }
}
```

---

## Why It Works

For BST:

```text
Left < Root < Right
```

Suppose:

```text
root = 6
p = 2
q = 4
```

Both nodes are smaller than root.

Therefore:

```text
LCA must be in left subtree
```

No need to search right subtree.

This reduces unnecessary traversal.

---

## Time Complexity

We move only along one path.

```text
Time = O(H)
```

where:

```text
H = Height of Tree
```

Balanced BST:

```text
O(log N)
```

Worst Case:

```text
O(N)
```

(skewed tree)

---

## Space Complexity

Recursion stack:

```text
Space = O(H)
```

---

# Solution 3: Iterative BST Solution (Most Optimized)

## Idea

Same logic as recursive solution.

Use a loop instead of recursion.

---

## Code

```java
class Solution {

    public TreeNode lowestCommonAncestor(TreeNode root,
                                         TreeNode p,
                                         TreeNode q) {

        while(root != null){

            if(p.val < root.val &&
               q.val < root.val){

                root = root.left;
            }
            else if(p.val > root.val &&
                    q.val > root.val){

                root = root.right;
            }
            else{
                return root;
            }
        }

        return null;
    }
}
```

---

## Time Complexity

```text
Time = O(H)
```

Balanced BST:

```text
O(log N)
```

Worst Case:

```text
O(N)
```

---

## Space Complexity

No recursion stack.

```text
Space = O(1)
```

---

# Complexity Comparison

| Solution | Time | Space |
|-----------|--------|--------|
| Binary Tree LCA | O(N) | O(H) |
| Recursive BST | O(H) | O(H) |
| Iterative BST | O(H) | O(1) |

# Interview Notes

### Brute Force

```text
Use Binary Tree LCA solution.

Time = O(N)

```

---

### Better

```text
Use BST property.

Move only left or right.

Time = O(H)
```

---

### Best

```text
Iterative BST solution.

Time = O(H)

Space = O(1)
```

# Final Takeaway

When you see:

```text
Lowest Common Ancestor of BST
```

Think:

```text
BST
↓
Left < Root < Right
↓
Both smaller?
Go Left

Both greater?
Go Right

Otherwise
Current node is LCA
```
