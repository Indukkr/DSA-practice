# 🌳 Binary Tree Right Side View — LeetCode #199

## 📌 Problem

Given the root of a binary tree, return the nodes that are visible when looking at the tree from the **right side**.

For every level, we need the **rightmost node**.

### Example

```text
        1
       / \
      2   3
       \   \
        5   4

Right side view:

1 → 3 → 4
```

---

# 🧠 Brute Force Thought Process

The first thought is:

> "For every level, I need to find the rightmost node."

So we can perform **Level Order Traversal (BFS)**.

At every level:

```text
1. Traverse all nodes
2. Keep track of the last node
3. Add that node to the answer
```

Because the nodes are processed from:

```text
left → right
```

the last node processed at each level is the rightmost node.

---

# 🚀 Approach — BFS / Level Order Traversal

We use a queue.

### Step 1

Add root:

```java
q.add(root);
```

### Step 2

For every level:

```java
int size = q.size();
```

`size` tells us how many nodes belong to the current level.

### Step 3

Process exactly `size` nodes.

```java
for(int i = 0; i < size; i++)
```

Since we add:

```text
left child first
right child second
```

the last node processed at that level is the rightmost node.

### Step 4

Add the last node to the answer.

---

# 💡 Important Observation

We don't actually need to store the entire level in a separate list.

We only need to know:

> "Is this the last node of the current level?"

So instead of:

```java
List<Integer> list = new ArrayList<>();
```

we can simply check:

```java
if(i == size - 1)
    ansList.add(temp.val);
```

This makes the solution cleaner.

# 🔧 Cleaner Version

We can avoid the temporary `list`:

```java
class Solution {
    public List<Integer> rightSideView(TreeNode root) {

        if (root == null)
            return new ArrayList<>();

        List<Integer> ansList = new ArrayList<>();

        Queue<TreeNode> q = new LinkedList<>();
        q.add(root);

        while (!q.isEmpty()) {

            int size = q.size();

            for (int i = 0; i < size; i++) {

                TreeNode temp = q.remove();

                // Last node of current level
                if (i == size - 1)
                    ansList.add(temp.val);

                if (temp.left != null)
                    q.add(temp.left);

                if (temp.right != null)
                    q.add(temp.right);
            }
        }

        return ansList;
    }
}
```

---

# 🧠 Why Does `i == size - 1` Give Rightmost?

Because we process nodes from:

```text
left → right
```

Example:

```text
Level:
[2, 3, 4, 5]

indices:
 0  1  2  3
          ↑
       last node
```

So:

```java
i == size - 1
```

means:

> "This is the last node of this level."

Therefore, it is the **rightmost visible node**.

---

# 🔄 Connection With Level Order Traversal

This problem is basically:

```text
Level Order Traversal
        +
Take last node of every level
```

Normal Level Order:

```text
1
2 3
4 5 6
```

Right Side View:

```text
1
  3
    6
```

So whenever you know BFS / Level Order Traversal, this problem becomes much easier.

# 🐢 Alternative Thought — DFS

Another way is DFS.

We can traverse:

```text
Right → Left
```

and record the **first node encountered at every depth**.

Why?

Because if we visit:

```text
right child first
```

the first node we encounter at a particular level is the rightmost visible node.

This gives:

```text
DFS:
Root → Right → Left
```

But your BFS solution is very natural because the problem is directly about **levels**.

---

# 🔧 DFS Version

```java
class Solution {

    public List<Integer> rightSideView(TreeNode root) {

        List<Integer> ans = new ArrayList<>();

        dfs(root, 0, ans);

        return ans;
    }

    private void dfs(TreeNode root, int level, List<Integer> ans) {

        if (root == null)
            return;

        // First node encountered at this level
        if (level == ans.size())
            ans.add(root.val);

        dfs(root.right, level + 1, ans);
        dfs(root.left, level + 1, ans);
    }
}
```

---

# 🔄 BFS vs DFS

| Approach | Idea | Time | Space |
|---|---|---:|---:|
| BFS | Last node of every level | O(n) | O(n) |
| DFS | First node at every level while visiting right first | O(n) | O(h) |

For your current preparation, remember **BFS first**, because it connects directly to Level Order Traversal.

# ⚠️ Common Mistakes

### 1. Taking the first node of every level

```java
if(i == 0)
```

❌ This gives the **left side view** when traversing left → right.

For right side:

```java
if(i == size - 1)
```

---

### 2. Forgetting to capture the level size

Don't do:

```java
while(!q.isEmpty()) {
    // process everything
}
```

You need:

```java
int size = q.size();
```

because we need to know where the current level ends.

---

### 3. Adding right child first and then taking last node

Your current logic:

```java
q.add(temp.left);
q.add(temp.right);
```

is correct.

Because the last node processed is then the rightmost node.

# 🎯 Interview Explanation

> "This problem can be solved using level-order traversal. I maintain a queue and process the tree level by level. For every level, I know its size from the queue before processing it. Since I add the left child before the right child, the last node processed in that level is the rightmost node. I add that node to the result."
