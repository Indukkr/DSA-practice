# LeetCode 112 - Path Sum

## Pattern

Tree + DFS + State Propagation

---

## Problem Statement

Given the root of a binary tree and an integer targetSum,
return true if the tree has a root-to-leaf path such that
adding up all the values along the path equals targetSum.

---

## Key Observation

This is not really a "sum" problem.

This is a:

```text
State Propagation Problem
```

At every node:

```text
Current State
↓
Update State
↓
Pass State to Children
```

The state can be:

```text
Current Sum
```

or

```text
Remaining Sum
```

---

# Solution 1: DFS + Running Sum

## Idea

Maintain current path sum.

At every node:

```text
sum += root.val
```

When reaching a leaf:

```text
sum == targetSum
```

then return true.

---

## Code

```java
class Solution {

    public boolean hasPathSum(TreeNode root,
                              int targetSum) {

        return dfs(root, targetSum, 0);
    }

    private boolean dfs(TreeNode root,
                        int targetSum,
                        int sum){

        if(root == null)
            return false;

        sum += root.val;

        if(root.left == null &&
           root.right == null){

            return sum == targetSum;
        }

        return dfs(root.left,targetSum,sum)
            || dfs(root.right,targetSum,sum);
    }
}
```

---

## Why It Works

Example:

```text
Target = 22

5
↓
4
↓
11
↓
2
```

Running Sum:

```text
0 + 5 = 5

5 + 4 = 9

9 + 11 = 20

20 + 2 = 22
```

Leaf reached:

```text
22 == 22
```

Return:

```text
true
```

---

## Time Complexity

Every node visited once.

```text
Time = O(N)
```

---

## Space Complexity

Recursion stack:

```text
Space = O(H)
```

where:

```text
H = Height of Tree
```

---

# Solution 2: DFS + Remaining Sum (Interview Preferred)

## Idea

Instead of maintaining current sum:

Maintain remaining sum.

At every node:

```text
targetSum -= root.val
```

When reaching a leaf:

```text
targetSum == 0
```

means path sum is found.

---

## Code

```java
class Solution {

    public boolean hasPathSum(TreeNode root,
                              int targetSum) {

        if(root == null)
            return false;

        targetSum -= root.val;

        if(root.left == null &&
           root.right == null){

            return targetSum == 0;
        }

        return hasPathSum(root.left,targetSum)
            || hasPathSum(root.right,targetSum);
    }
}
```

---

## Why It Works

Example:

```text
Target = 22
```

At:

```text
5
```

Remaining:

```text
22 - 5 = 17
```

At:

```text
4
```

Remaining:

```text
17 - 4 = 13
```

At:

```text
11
```

Remaining:

```text
13 - 11 = 2
```

At:

```text
2
```

Remaining:

```text
2 - 2 = 0
```

Leaf reached:

```text
targetSum == 0
```

Return:

```text
true
```

---

## Why Is This Preferred?

Cleaner.

No extra variable.

Directly represents:

```text
How much sum is still needed?
```

This is usually the solution interviewers expect.

---

## Time Complexity

Every node visited once.

```text
Time = O(N)
```

---

## Space Complexity

Recursion stack.

```text
Space = O(H)
```

# Solution 3: Iterative DFS

## Idea

Use Stack.

Store:

```text
Node
+
Current Sum
```

Process nodes iteratively.

---

## Code

```java
class Pair {

    TreeNode node;
    int sum;

    Pair(TreeNode node,int sum){
        this.node = node;
        this.sum = sum;
    }
}

class Solution {

    public boolean hasPathSum(TreeNode root,
                              int targetSum) {

        if(root == null)
            return false;

        Stack<Pair> stack = new Stack<>();

        stack.push(new Pair(root, root.val));

        while(!stack.isEmpty()){

            Pair current = stack.pop();

            TreeNode node = current.node;
            int sum = current.sum;

            if(node.left == null &&
               node.right == null &&
               sum == targetSum){

                return true;
            }

            if(node.right != null){
                stack.push(
                    new Pair(node.right,
                             sum + node.right.val));
            }

            if(node.left != null){
                stack.push(
                    new Pair(node.left,
                             sum + node.left.val));
            }
        }

        return false;
    }
}
```

---

## Time Complexity

```text
Time = O(N)
```

---

## Space Complexity

```text
Space = O(H)
```

---

## Interview Flag 🚩

### Why Is BFS/DFS Iterative Not Preferred?

Works perfectly.

But:

```text
More code
Extra Pair class
Less elegant
```

Recursion is simpler and easier to explain.
