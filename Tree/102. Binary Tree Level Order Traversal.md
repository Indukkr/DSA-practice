# 🌳 Binary Tree Level Order Traversal — LeetCode #102

## 📌 Problem

Given the root of a binary tree, return the **level order traversal** of its nodes' values.

Level order means:

> Visit the tree level by level, from left to right.

### Example

```text
        3
       / \
      9   20
         /  \
        15   7

Level Order:

[3]
[9, 20]
[15, 7]

Output:

[[3], [9, 20], [15, 7]]
```

---

# 🧠 Brute Force Thought Process

The first thought is:

> "I need to visit the nodes level by level."

A normal DFS traversal does not naturally process nodes level by level.

For example:

```text
Preorder  → Root → Left → Right
Inorder   → Left → Root → Right
Postorder → Left → Right → Root
```

These traversals focus on the tree structure, not levels.

We could use DFS and maintain the `level/depth` of every node, but that adds extra logic.

Since the problem itself asks for:

```text
Level 0
Level 1
Level 2
...
```

**BFS is the most natural approach.**

---

# 🚀 Approach — BFS / Level Order Traversal

We use a **Queue** because Queue follows:

```text
FIFO
First In → First Out
```

This allows us to process nodes level by level.

### Step 1

If the tree is empty:

```java
if(root == null)
    return new ArrayList<>();
```

### Step 2

Create the answer list and queue.

```java
List<List<Integer>> ansList = new ArrayList<>();

Queue<TreeNode> queue = new LinkedList<>();
```

### Step 3

Add the root:

```java
queue.add(root);
```

### Step 4

While the queue is not empty:

```java
while(!queue.isEmpty())
```

Get the number of nodes in the current level:

```java
int size = queue.size();
```

`size` tells us:

> How many nodes belong to the current level?

### Step 5

Process exactly `size` nodes:

```java
for(int i = 0; i < size; i++)
```

For every node:

```text
1. Remove node from queue
2. Add its value to current level
3. Add left child
4. Add right child
```

### Step 6

After processing the complete level, add that level to the answer.

# 💡 Important Observation

The key to solving this problem is:

```java
int size = queue.size();
```

This tells us:

> How many nodes belong to the current level?

Suppose:

```text
Queue = [9, 20]
```

Then:

```text
size = 2
```

So:

```text
9 and 20 → Current Level
```

While processing them, we add:

```text
15 and 7
```

The queue becomes:

```text
[15, 7]
```

But we **don't process them in the current level**, because our loop only runs `size = 2` times.

Therefore:

```text
Current Level → 9, 20
Next Level    → 15, 7
```

This is how we separate the levels.

# 🔧 Your Approach

Your implementation follows the standard BFS pattern:

```java
int size = queue.size();
List<Integer> list = new ArrayList<>();

for(int i = 0; i < size; i++){

    TreeNode temp = queue.remove();

    list.add(temp.val);

    if(temp.left != null)
        queue.add(temp.left);

    if(temp.right != null)
        queue.add(temp.right);
}

ansList.add(new ArrayList<>(list));
```

This is a **correct and standard Level Order Traversal solution**.

# 🔧 Your Code

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
    
        if(root == null)
            return new ArrayList<>();

        List<List<Integer>> ansList = new ArrayList<>();

        Queue<TreeNode> queue = new LinkedList<>();

        queue.add(root);

        while(!queue.isEmpty()){

            int size = queue.size();
            List<Integer> list = new ArrayList<>();

            for(int i = 0; i < size; i++){

                TreeNode temp = queue.remove();

                list.add(temp.val);

                if(temp.left != null)
                    queue.add(temp.left);

                if(temp.right != null)
                    queue.add(temp.right);
            }

            ansList.add(new ArrayList<>(list));
        }

        return ansList;
    }
}
```

# 🔧 Cleaner Version

Since `list` is created fresh inside every `while` iteration, we can directly add it:

```java
ansList.add(list);
```

So the cleaner version is:

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {

        if(root == null)
            return new ArrayList<>();

        List<List<Integer>> ansList = new ArrayList<>();

        Queue<TreeNode> queue = new LinkedList<>();
        queue.add(root);

        while(!queue.isEmpty()){

            int size = queue.size();
            List<Integer> list = new ArrayList<>();

            for(int i = 0; i < size; i++){

                TreeNode temp = queue.remove();

                list.add(temp.val);

                if(temp.left != null)
                    queue.add(temp.left);

                if(temp.right != null)
                    queue.add(temp.right);
            }

            ansList.add(list);
        }

        return ansList;
    }
}
```

# 🧠 Why Do We Use a Queue?

Queue follows:

```text
FIFO
First In → First Out
```

Consider:

```text
        1
       / \
      2   3
     / \
    4   5
```

Initially:

```text
Queue = [1]
```

Remove `1` and add its children:

```text
Queue = [2, 3]
```

Remove `2` and `3`:

```text
Queue = [4, 5]
```

Therefore, the queue naturally gives:

```text
[1]
[2, 3]
[4, 5]
```

Which is exactly the required level order.

# 🔄 BFS vs DFS

There are two possible approaches.

## BFS

```text
Queue
  ↓
Level by level
  ↓
Natural solution
```

## DFS

We can also use DFS by maintaining the level/depth:

```text
DFS(node, level)
```

and adding values into:

```text
ans[level]
```

But because the problem explicitly asks for level-wise traversal, **BFS is simpler and more intuitive**.

For this problem, remember **BFS first**.

---

# 🔧 DFS Version

For understanding the alternative:

```java
class Solution {

    public List<List<Integer>> levelOrder(TreeNode root) {

        List<List<Integer>> ans = new ArrayList<>();

        dfs(root, 0, ans);

        return ans;
    }

    private void dfs(TreeNode root, int level, List<List<Integer>> ans) {

        if(root == null)
            return;

        if(ans.size() == level)
            ans.add(new ArrayList<>());

        ans.get(level).add(root.val);

        dfs(root.left, level + 1, ans);
        dfs(root.right, level + 1, ans);
    }
}
```

But:

> **BFS is the most natural solution for Level Order Traversal.**

# ⚠️ Common Mistakes

### 1. Forgetting `size = queue.size()`

Wrong:

```java
while(!queue.isEmpty()) {
    // process nodes
}
```

You need:

```java
int size = queue.size();
```

because we need to know how many nodes belong to the current level.

---

### 2. Processing newly added children in the same level

Suppose:

```text
Queue = [2, 3]
```

While processing them, we add:

```text
[4, 5]
```

We should **not** process `4` and `5` in the same level.

That's why:

```java
for(int i = 0; i < size; i++)
```

is important.

---

### 3. Forgetting to add both children

For every node:

```java
if(temp.left != null)
    queue.add(temp.left);

if(temp.right != null)
    queue.add(temp.right);
```

Both children need to be added.

---

### 4. Forgetting the null root case

If:

```text
root = null
```

the answer should be:

```text
[]
```

# 🎯 Interview Explanation

> "I will use BFS because the problem requires level-wise traversal. I maintain a queue and add the root initially. At the beginning of each level, I store the queue size, which tells me how many nodes belong to the current level. I process exactly those nodes, add their values to a temporary list, and add their children to the queue. After processing the complete level, I add that list to the answer. Every node is visited once, so the time complexity is O(n) and the space complexity is O(n)."

# 🔥 Pattern Recognition

Whenever you see:

```text
Level by level
Each level separately
Nodes at depth K
Rightmost/Leftmost node of each level
Average of each level

```

Think:

```text
Binary Tree
     ↓
BFS
     ↓
Queue
     ↓
Level-by-Level Processing
```

The standard template is:

```java
int size = queue.size();

for(int i = 0; i < size; i++) {

    TreeNode node = queue.remove();

    // process node

    if(node.left != null)
        queue.add(node.left);

    if(node.right != null)
        queue.add(node.right);
}
```

### Right Side View


### Left Side View

```text

    ↓

```

### Average of Levels

```text
Level Order
    ↓
```

```text
    ↓
```

The queue can contain up to `O(n)` nodes in the worst case.

```text
O(n)
```

```text
        ↓

        ↓

        ↓
```
