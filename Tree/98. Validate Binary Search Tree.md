# LeetCode 98 - Validate Binary Search Tree

## Pattern

Tree + DFS + Range Propagation

---

## Initial Thought Process

My first idea was to check only the immediate children:

```java
node.left.val < node.val
node.right.val > node.val
```

This fails because BST constraints come from all ancestors, not just the parent.

Example:

```text
      5
     / \
    4   6
       / \
      3   7
```

At node `6`:

- `3 < 6` ✅
- `7 > 6` ✅

Everything looks valid locally.

However, node `3` belongs to the right subtree of `5`.

Therefore:

```text
3 > 5
```

must also be true, which is false.

### Conclusion

Checking only parent-child relationships is insufficient.

---

## Key Observation

Every node must satisfy constraints imposed by all of its ancestors.

Instead of thinking:

```text
left < current < right
```

Think:

```text
min < current < max
```

where `min` and `max` are inherited from ancestor nodes.

---

## Recursive Definition

```java
validate(node, min, max)
```

Meaning:

> Is the subtree rooted at `node` a valid BST where:

```text
min < node.val < max
```

---

## Example

```text
        10
       /  \
      5    15
```

For root:

```java
validate(10, -∞, +∞)
```

For left child:

```java
validate(5, -∞, 10)
```

For right child:

```java
validate(15, 10, +∞)
```

---

## Base Case

```java
if(node == null)
    return true;
```

### Why?

An empty tree is always a valid BST.

---

## Current Node Validation

```java
if(node.val <= min || node.val >= max)
    return false;
```

This checks whether the current node violates its allowed range.

Example:

```java
validate(6, 10, 15)
```

Allowed range:

```text
10 < 6 < 15
```

which is invalid.

---

## Recursive Calls

### Left Subtree

```java
validate(node.left, min, node.val)
```

All nodes in the left subtree must be smaller than the current node.

### Right Subtree

```java
validate(node.right, node.val, max)
```

All nodes in the right subtree must be greater than the current node.

---

## Combining Results

```java
return validate(node.left, min, node.val)
    && validate(node.right, node.val, max);
```

Both subtrees must be valid.

---

## Edge Case

My initial implementation used:

```java
Integer.MIN_VALUE
Integer.MAX_VALUE
```

This fails when:

```java
root.val == Integer.MIN_VALUE
```

because:

```java
node.val <= min
```

becomes:

```java
Integer.MIN_VALUE <= Integer.MIN_VALUE
```

which incorrectly returns `true`.

### Fix

Use:

```java
Long.MIN_VALUE
Long.MAX_VALUE
```

and make `min` and `max` of type `long`.

---

## Final Solution

```java
class Solution {

    public boolean isValidBST(TreeNode root) {
        return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    private boolean validate(TreeNode node, long min, long max) {

        if(node == null)
            return true;

        if(node.val <= min || node.val >= max)
            return false;

        return validate(node.left, min, node.val)
                && validate(node.right, node.val, max);
    }
}
```

---

## Complexity Analysis

### Time Complexity

`O(n)`

Every node is visited exactly once.

### Space Complexity

`O(h)`

where `h` is the height of the tree.

- Balanced Tree → `O(log n)`
- Skewed Tree → `O(n)`

---

## Mistakes Made

1. Checked only parent-child relationships.
2. Forgot that descendants must satisfy ancestor constraints.
3. Used `Integer.MIN_VALUE` and `Integer.MAX_VALUE` as boundaries.
4. Failed edge cases involving integer limits.
5. Fixed by using `long` boundaries.

---

## Revision Summary

- BST validation requires ancestor constraints.
- Pass a valid range `(min, max)` to every node.
- Left subtree → `(min, node.val)`
- Right subtree → `(node.val, max)`
- If a node violates the range, return `false`.
- Use `Long.MIN_VALUE` and `Long.MAX_VALUE` for boundaries.
- Pattern: **DFS + Range Propagation**
